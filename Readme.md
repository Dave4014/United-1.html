# MyProject2

**Author**: James Leach

A web application featuring an image gallery and GIF search engine.

## Features

- **Image Gallery**: Display of curated images in a responsive grid layout
- **GIF Search**: Search and display GIFs from the Giphy API
- **Contact Form**: Get in touch page
- **Responsive Design**: Built with Bootstrap 5.3.8

## Getting Started

1. Clone the repository
2. Ensure all image files are in the project root
3. Include Bootstrap files in the `bootstrap-5.3.8-dist` folder
4. Open `index.html` in a web browser

## Pages

- `index.html` - Home page with image gallery
- `searchengine.html` - GIF search interface
- `contactform.html` - Contact form

## Technologies

- HTML5
- CSS3
- JavaScript (jQuery)
- Bootstrap 5.3.8
- Giphy API

## API

Uses the Giphy API for GIF search functionality. API key is included in `searchengine.js`.
